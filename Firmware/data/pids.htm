Peltie Voltage Controller

Outer PID (fermenter temperature to box target)

This slow loop changes the box-air target to control the fermenter. Tune from real temperature logs, one setting at a time; make small changes and wait several iSpindel reports before judging the result. Defaults are conservative starting values, not guaranteed final tuning.

ParameterValue and effect
P (Kp)
Immediate response to liquid temperature error. Higher Kp moves the box target farther for the same error, correcting faster but increasing the risk of overshoot or oscillation. If the response is too aggressive, lower Kp.
I (Ki per hour)
Slowly builds a box-target offset to compensate for persistent error and changing ambient conditions. Higher Ki removes a lasting error sooner, but can cause overshoot as the liquid responds slowly. If it crosses the setpoint or keeps drifting after reaching it, lower Ki. Ki must be greater than zero.
D horizon (Td, hours)
How far ahead the filtered liquid-temperature trend is projected. A larger Td makes D counteract a rise or fall earlier and more strongly; too much may slow correction. Set to 0 to turn off D.
D forecast limit (°C)
Caps the predicted temperature change used by D, which also caps D's influence on the box target. Raise it for more trend compensation; lower it if D weakens heating/cooling too much. Set to 0 to remove D output.
I freeze rate (°C/hour)
When the liquid is moving toward its target faster than this rate, I is paused to avoid accumulating extra correction during the slow thermal response. Lower values pause I more often; higher values let I continue longer. Set to 0 to disable this trend-based freeze.
Max box target offset (°C)
Hard limit on how far the outer loop may set the box target above or below the fermenter setpoint. A higher limit permits stronger correction but allows more extreme box targets; keep it within safe limits for the contents and hardware. This is separate from the box-target slew rate below.

D is calculated from the filtered iSpindel trend, not from raw differences between reports. Its contribution is approximately −Kp × the limited predicted temperature change. The box target also has a separate rate-of-change limit, so it may move gradually even when the PID asks for a larger change.


Inner heater PID (box air temperature to heater PWM)

These settings tune only the fast air-temperature heater loop. They do not tune the fermenter outer PID above. Use the Heating Autotune below as a starting point, then verify carefully; changes can affect heater response and safety.

ParameterValue
P
How strongly heater PWM responds to the current box-air temperature error. Higher P gives a stronger immediate response, but too much can cause rapid swings.
I
Accumulates persistent box-air error to reduce steady offsets. Higher I corrects them faster but may keep heating after the target is reached.
D
Responds to how quickly box-air temperature is changing to reduce heater output before overshoot. Too much D can make output sensitive to sensor noise.
